## Contracts / decisions
- Check folder schema `baradwatchu.custom-checks.v1` (fields: schemaVersion,id,name,description,priority,enabled,toolPath,arguments,expectedSha256,version,timeoutSeconds?,parameters,overrideBuiltinId; deny unknown). id == folder name; custom IDs `CUSTOM-[A-Z0-9-]+`.
- Tools run via direct exec (no shell): scripts need a `#!` line; ENOEXEC → ERROR "Requirement tool has no valid interpreter line" + fix hint (`spawn_failure` in requirements.rs). Other spawn errors include the OS error in details.
- Custom dir `$XDG_CONFIG_HOME/baradwatchu/custom-checks` (decided 2026-11-07 per operator); legacy `custom-tools` auto-renamed once if `custom-checks` absent.
- Invalid custom folder ⇒ ERROR control with `configurationError` reason, never breaks catalog; invalid builtin ⇒ hard error. Non-`CUSTOM-` folder names ⇒ `ignoredFolders`.
- Integrity gate (2026-11-07, supersedes M6 "mismatch still executes"): hash checked before every run, builtin and custom; mismatch/missing hash ⇒ ERROR, tool NOT executed. Re-pin: `custom accept ID` / dashboard accept (version+1 if hash changed) / dashboard upload.
- Runner: direct exec, cwd = tool folder, own process group (killed on timeout and after exit), clean env, PATH `/usr/bin:/bin` (+`~/.local/bin` custom), stdout ≤64 KiB, stderr ≤4 KiB shown on failure, timeout per check (default 20 s, REQ-001 90 s, max 300). Custom tools run from a private snapshot of hashed bytes.
- Custom stdout: `{status: PASS|FAIL|WARNING|ERROR, summary, details?: string|string[]}`; builtins also `id`.
- API/`list --json`: Requirement serialized camelCase (bug fixed 2026-11-07: snake_case broke dashboard delete/override/hash display).
- CLI validates command shape before touching disk; `custom accept|remove` work without a valid catalog.
- Builtin criteria aligned to REQUIREMENTS §5 + skill R1–R7 (2026-11-07): REQ-002 explicit off ⇒ FAIL; REQ-004 one complete method suffices (dnsmasq active+enabled+≥1000 rules, or hosts ≥10000 entries; resolv.conf non-loopback = observation) — operator confirmed 2026-11-07, supersedes "hosts only if dnsmasq absent"; REQ-006 adds CryFS + home coverage detail; REQ-007 timeout ≤5, LockGrace ≤0, LockOnResume; REQ-008 adds warning ≥10, login.defs PASS_MAX_DAYS, u/l/d/ocredit -1. Thresholds = config parameters.
- M7 tray decisions (2026-11-07): separate process; agent↔tray = agent CLI subprocess, fixed commands, no shell, agent = sibling binary (no PATH); no new IPC. Linux tray via tray-icon `ksni` (no GTK). Native notifications owned by tray; dashboard audits no longer notify-send; CLI `audit --notify` kept. One event per audit (INTEGRITY_ISSUE>AUDIT_ERROR>AUDIT_ANOMALIES>AUDIT_COMPLETED), `repeated` ⇒ informative. Prefs `{enabled, informative}`; ACTION (consent) never silenced. Tray: poll 5 s, first poll sets cursor (no backlog), ≤3 notes/poll, unreachable after 2 failures once + recovery once.
- Consent (M7, local only): schema `baradwatchu.consent-request.v1`, files `$XDG_STATE_HOME/baradwatchu/consent/<32hex>.json`, TTL 10–3600 s (default 120), source LOCAL_SIMULATION only; only explicit accept authorizes one request; expired/late refused; decidedVia CONSENT_WINDOW|CLI; dashboard can only simulate. zenity: Accetta / «Decidi più tardi» (default) / extra Rifiuta, `--timeout`; kdialog fallback killed at expiry.
- Paths: audit history `$XDG_CACHE_HOME/baradwatchu/audit/{reports/*.json,*.log}` (moved from state/audits 2026-11-08 per operator; disposable, one-time best-effort rename, no auto-pruning), events `$XDG_STATE_HOME/baradwatchu/events.jsonl` (200), prefs `$XDG_CONFIG_HOME/baradwatchu/notifications.json`, runtime `$XDG_RUNTIME_DIR/baradwatchu/{dashboard.json,open-dashboard.html,tray.lock}` (fallback state/run). TestEnv/integration tests also isolate XDG_CACHE_HOME and XDG_RUNTIME_DIR.
- Installer: [REQUIRED] build + runtime (bash, python3, awk, sed, grep, coreutils) block; [optional] audit tools Arch-only with alternative groups (firewall, vpn); options summary first; running instances of `$PREFIX/bin/baradwatchu-agent` matched by /proc exe ⇒ SIGTERM, wait `BARADWATCHU_STOP_TIMEOUT` (10 s), never SIGKILL, fail if alive; internal `--reexec` flag for sudo re-exec (install no longer `exec`s sudo: parent runs `post_install_user` after). M7: tray default (`--without-tray` ⇒ cargo `-p baradwatchu-agent`, marker `tray=0`), rustc ≥1.92 with tray, `--tray-autostart` (as invoking user), uninstall removes user autostart if Exec points to prefix, running tray SIGTERMed, manifest adds `bin/baradwatchu-tray` + `share/applications/baradwatchu-tray.desktop` (36 files with tray, 34 without).
